# Customer Go-Live Script (Week 1)

## 1) Intro (2 minutes)

Welcome to your new sales workspace.  
This platform helps your team do three things faster:

- capture leads from every channel,
- follow up quickly and consistently,
- convert more leads into closed deals.

By the end of this session, your team will have:

- integrations connected,
- first leads imported,
- first deal created,
- first WhatsApp follow-up sent.

---

## 2) Setup Checklist Walkthrough (5 minutes)

From the dashboard:

1. Open **Quick actions** (bottom-right).
2. Click **Launch setup guide**.
3. Complete each item:
   - Connect integrations
   - Import first leads
   - Create first deal
   - Send first follow-up
   - Complete first task

The checklist auto-updates as each step is completed.

---

## 3) Integration Setup (10 minutes)

Go to **Settings -> Integrations** and configure:

- Meta Lead Ads (optional if not running ads yet)
- WhatsApp Cloud API
- SMS (Termii)

Success criteria:

- Integration health block on dashboard shows **Connected**.
- Webhook last event timestamp appears after first inbound event.

---

## 4) Import Leads (5 minutes)

Go to **Leads -> Import CSV**:

- Upload template CSV
- Review preview and valid rows
- Import

Success criteria:

- Leads appear in list
- Scores are visible
- Hot leads are highlighted

---

## 5) Create Pipeline Motion (8 minutes)

Go to **Deals**:

- Create first deal from a lead
- Move stage in Kanban or List view
- Confirm stage updates in timeline

Success criteria:

- Deal appears in pipeline
- Owner can update stage
- Team can see updated status

---

## 6) Omnichannel Usage (8 minutes)

Go to **Activities** (Omnichannel Inbox):

- Filter by channel (All / Activities / WhatsApp)
- Open WhatsApp card and send reply inline
- Mark one pending task as done

Success criteria:

- Inbound and outbound WhatsApp both appear
- Reply sends successfully from inbox
- Task completion updates immediately

---

## 7) Day-1 Operating Rhythm (for Sales Manager)

Every morning:

1. Open dashboard setup/health block.
2. Check unassigned leads and open tasks.
3. Review Omnichannel inbox for new WhatsApp messages.
4. Ensure each hot lead has an owner and next action.

Every evening:

1. Review deals moved today.
2. Check overdue tasks.
3. Verify next-day follow-ups are scheduled.

---

## 8) Talking Points for Customer Teams

Use this exact message:

> "This system is now your single source of truth for leads, deals, and follow-ups.  
> Every lead must have an owner, every owner must have a next action, and every action must be logged in the inbox.  
> If it is not in this system, it did not happen."

---

## 9) Support Escalation Template

If customer reports an issue, capture:

- Tenant slug
- Role of affected user
- Page URL
- Timestamp
- Screenshot
- Expected behavior vs actual behavior

Response promise:

- Acknowledge within 15 minutes
- First diagnosis within 1 hour
- Workaround or fix ETA same day

---

## 10) First-Week Success Metrics

Track daily:

- % leads assigned within 15 minutes
- # WhatsApp replies sent from inbox
- # overdue tasks
- # deals moved stages

Target by end of week:

- 90% leads assigned same day
- 0 critical setup blockers
- team actively using inbox + checklist
